### D 统一控制台 / 皮套
- `GET /console` → 488 B 的 `dist/index.html`，`GET /assets/index-*.js` 200（125 KB）、`/icon.png` 200。
- `GET /api/live2d/models` → `{models:[{name:'avatar',path:'/live2d/models/avatar/c_0120.model3.json'}], current:...}`；`POST /api/live2d/model` 切换成功并写回 config；`/live2d` 页面没带 `?model=` 时会自己读当前模型。

### C 抖音中继（本地假直播间全链路）
用 `file:///.../fake_douyin.html`（模拟抖音聊天 DOM：昵称 span + 正文 span + room-message）跑：
- Chrome 启动 → CDP 连上 → 采集脚本注入 → 分类 → 入站：`{"danmaku":3,"gift":1,"enter":1,"follow":1,"like":1}`，`room-message`（系统提示）被正确忽略。
- 控制台「一键启动中继」走的是 deps 同一套：`命令 = node extras/douyin/relay.js --api ... --rid ... --url ...`，状态从「中继没在跑」→「中继在跑（心跳 10s 前，最近事件 9s 前）」；「停止」后 relay + 7 个 Chrome 进程全部清掉。
- 真直播间待你扫码登录后实测一次（`%LOCALAPPDATA%\jinglive-douyin-profile` 会记登录态）。

### 打包路径适配

## 三、现在怎么用

```bash
# 开发版（源码）
npm run electron                        # 起核心 8788 + 打开控制台窗口

# 浏览器也能用同一套控制台
start http://127.0.0.1:8788/console

# 依赖服务：控制台 → 系统设置 → 运行环境 → 一键启动（TTS / 抖音中继 / OBS / Ollama）
# 抖音接入细节：docs/抖音接入.md
# 运行环境字段/自动发现规则：docs/运行环境.md

# 打包
npm run build:exe        # release\鲸live-0.1.0-portable.exe（约 76 MB）
npm run build:installer  # release\鲸live-0.1.0-setup.exe（约 90 MB，per-user 免管理员）
```
