# 鲸语移植版（Vue + Electron）

把原版 WhaleTalk（PyInstaller exe）的功能搬到 **Node/Electron**，**保持原有 HTTP API 兼容**，
所以原来的中继（gift_scraper）、OBS 网页源、看门狗脚本都可以继续用，不需要改。

## 先说结论：能移植，且核心已跑通

| 能力 | 状态 | 说明 |
|---|---|---|
| 会话开始/结束 | ✅ 已移植 | `/api/session/start` `/api/session/stop` |
| 抖音事件接入（relay） | ✅ 已移植 | `POST /api/douyin/ingest`，兼容原中继投递格式 |
| 进房/弹幕/礼物/关注/点赞 | ✅ 已移植 | 冷却、概率、合并窗口、模板 |
| 固定回复 | ✅ 已移植 | `fixed_replies: [{keywords, reply}]` |
| DeepSeek AI 回复 | ✅ 已移植 | 实测出句：「咕噜咕噜，宝子咱不知道呀」 |
| TTS（GPT-SoVITS） | ✅ 已移植 | POST `9881/tts` + Python 播放（依赖本机 9881 代理） |
| 弹幕层 / 歌单 / 控制台 | ✅ 已移植 | `/overlay` `/songs` `/dashboard` |
| 点歌 | ✅ 兼容 | 「点歌 xxx」写入 `tools/logs/song_requests.jsonl`，由现有点歌系统处理 |
| OBS 网页源 | ✅ 直接可用 | 弹幕层地址换端口即可 |
| Live2D 皮套渲染 | ⏳ 待移植 | 原版页面在 exe 里；建议用 pixi-live2d-display 重写 |
| 自动歌单/播放 | ⏳ 保留 Python | 现由 `tools/songbot.py` 播，Node 端只做队列/状态代理 |
| AI 思考模式 / 限流看门狗 | ⏳ 待移植 | 逻辑简单，后续补 |

## 目录

```
whaletalk_app/
├─ server/core.cjs      # 核心服务：HTTP API + WS + AI + TTS + 事件（零 npm 依赖）
├─ server/index.cjs     # 独立启动：node server/index.cjs --port 8788
├─ public/              # dashboard / overlay / songs 三个页面
├─ electron/main.cjs    # Electron 主进程：内嵌启动服务 + 打开窗口
├─ src/App.vue          # Vue 版控制台（需要安装依赖后构建）
├─ package.json         # electron + vite + vue
└─ config.json          # 从鲸语配置生成（AI key / TTS 参考音频 / 人设）
```

## 立即可用（不需要装任何 npm 依赖）

```bash
node server/index.cjs --port 8788
```

- 控制台：http://127.0.0.1:8788/dashboard
- 弹幕层（OBS 用）：http://127.0.0.1:8788/overlay
- 歌单（OBS 用）：http://127.0.0.1:8788/songs

OBS 把原来的 `http://127.0.0.1:8787/overlay` 改成 `8788` 即可。

## Electron + Vue 版（需要装依赖）

```bash
pnpm install        # 或 npm install
pnpm dev            # Vue 开发模式（Vite，API 仍走 8788）
pnpm electron       # 打开 Electron 桌面窗口（内部自动起服务）
pnpm app            # 构建 Vue + 打开 Electron
```

> 说明：Electron 只负责窗口与打包；后端逻辑在 `server/core.cjs`，与纯 Node 模式完全一致，
> 所以「不装 Electron 也能跑服务」——方便先上线，再慢慢换壳。

## 和原版的差异

1. **TTS 仍用本机 Python 引擎**（9881 代理 → 9882 GPU），Node 只发请求 + 播放 wav；
   以后要纯 Node，可换成 edge-tts 直连或 local tts 服务。
2. **Live2D 皮套**：原版页面打包在 exe 内。若继续用原版 OBS 源（8787/live2d），
   可以让原版只负责皮套、移植版负责其余；彻底替换需要接 `pixi-live2d-display`。
3. **点歌播放**：继续用现成的 `tools/songbot.py`（稳定），Node 端做队列/播报/状态代理。
