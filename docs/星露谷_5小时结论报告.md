## 五、没解决的问题：卖东西换金币

你的要求是「卖东西换钱，石头/木材各留 900」。目前 **金币还是 9**，原因：

- 农场的发货箱是 `ShippingBin` 建筑，箱子存在 `buildingChests`（NetList）字段里
- 但这个档的 `buildingChests` **是空的**（游戏还没创建箱子实例）
- 试过 4 种 API 全部失败：`GetBuildingChest` / `getShippingBin` / `PerformBuildingChestAction` / `GetBuildingChestData`
- 递归扫描建筑字段也找不到 Chest

**下一步两个方案**：
1. 走店铺 UI：进 Pierre / Clint 店 → 打开 ShopMenu → 调 `sellToShop`（需要白天、店主在）
2. 强制给发货箱创建 Chest 实例（构造 NetRef，风险高，可能崩档）
