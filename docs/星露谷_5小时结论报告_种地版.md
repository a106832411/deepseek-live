## 三、发现并修复的 bug：收获失效

**现象**：每轮日志都显示「收获 19 个作物」，但背包里没有小麦，作物一直显示可收获 → 死循环空转。

**原因**：原来用 `Game1.currentLocation.checkAction(tile)` 模拟收货，返回 True 但实际没把作物收进背包。

**修复**：新增 mod 动作 `harvest_crop`，直接调用游戏内部的 `Crop.harvest(...)`，收完清除作物。

**修复后实测**：
```
harvest clicks 18
wheat 19
卖 小麦: 点掉 1 叠，金币 -> 567
```
**金币 92 → 567（+475，19 个小麦 × 25g）** ✅
