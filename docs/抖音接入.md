# 抖音接入（内置中继）

鲸live 不再需要自己写中继脚本：仓库自带 `extras/douyin/relay.js`，控制台「系统设置 → 运行环境 → 抖音弹幕中继 → 一键启动」即可。

## 一、原理

```
Chrome（打开直播间网页，静音）
   ↑ CDP（本机调试端口 9333）
relay.js（Node，零依赖）
   ├─ 在页面里挂 MutationObserver 读聊天 DOM
   ├─ 正则分类：弹幕 / 进房 / 礼物 / 关注 / 点赞 / 粉丝团
   └─ POST 到鲸live 的 /api/douyin/ingest（同时每 15 秒心跳 /api/douyin/heartbeat）
```

- **不用抖音私有 WebSocket、不用签名**：读的是网页已经渲染出来的聊天列表，登录状态靠 Chrome profile 保留。
- 不点页面、不发消息，只读 DOM；Chrome 静音，不会影响你放别的音。
- 礼物价格用内置常用价目表（抖币 → 元）折算 `value`，AI 回复里可以用它判断感谢力度。

## 二、用法

### 1. 控制台一键启动（推荐）

1. 先确认 `config.json` 里 `douyin.web_rid` / `douyin.room_url` 填的是你的直播间
2. 打开「系统设置 → 🧰 运行环境」，找 **📺 抖音弹幕中继** → 点「一键启动」
3. 弹出的 Chrome 会打开直播间；**首次要扫码登录**，登录状态存在
   `%LOCALAPPDATA%\jinglive-douyin-profile`，以后不用再登
4. 回到控制台：状态变成「中继在跑，最近一条事件 Xs 前」就通了；开个会话发条弹幕试试
5. 停止：同一个页面点「停止」（会连它开的 Chrome 一起收掉，`taskkill /T`）

> 注意：连上后别按 F5 刷新直播间；Chrome 窗口别关（关了中继会自己退出并提示）。

### 2. 命令行

```bash
# 用 config.json 里的直播间
node extras/douyin/relay.js

# 指定直播间 / 鲸live 地址 / 调试端口
node extras/douyin/relay.js --rid 447058766923 --api http://127.0.0.1:8788 --port 9333

# 换个 Chrome profile（多账号/多直播间时有用）
node extras/douyin/relay.js --profile D:\tmp\douyin-profile2
```

参数全表：`--rid` `--url` `--api` `--port` `--profile` `--chrome` `--match` `--keep-chrome` `--once`。

### 3. 仍然支持外部中继

不想用内置的也行：任何脚本把事件 `POST /api/douyin/ingest`（`{events:[...]}`）就等价于中继在跑。
建议顺手每 15 秒 `POST /api/douyin/heartbeat`，控制台就能区分「中继活着但没弹幕」和「中继根本没跑」。

## 三、事件格式（和 core.cjs 的 handleEvent 一致）

```json
{"type":"danmaku","name":"观众A","text":"你好呀"}
{"type":"gift","name":"观众B","gift":"小心心","num":2,"value":0.2}
{"type":"enter","name":"观众C"}
{"type":"follow","name":"观众D"}
{"type":"like","name":"观众E"}
```

## 四、排障

| 现象 | 处理 |
|---|---|
| 启动后一直「中继没在跑」 | 看 `logs/deps-douyin.log`：Chrome 没装？`--chrome` 指定；页面 90 秒没到直播间？在弹出来的 Chrome 里看看是不是要登录/风控 |
| 显示「中继进程还在，但最近没收到弹幕」 | 直播间没人说话 / 页面卡住了。Chrome 里手动刷新一次直播间（中继会自动重新注入采集脚本） |
| 弹幕重复出现 | 页面刷新后旧消息会重新出现；中继有 10 分钟本地去重，但同名同内容的重复发言也会被去掉（这是刻意的） |
| 礼物不显示 / 表情昵称乱 | 抖音会改 DOM 类名，`ITEM_SEL`、nickname/content 选择器在 `relay.js` 顶部，按 F12 看当前类名改就行 |
| `CDP 已断开` 后退出 | 直播间页面被关了或导航到了别处；重开直播间再点一键启动 |
| 端口 9333 被占用 | 传 `--port 9334`（控制台启动默认用 9333，可从 `deps.douyin_start_cmd` 自己写命令改） |

## 五、已知限制

1. **依赖 Chrome**（Edge 也可，脚本会自动找）；没装浏览器就没法抓。
2. **首次要登录**：抖音未登录的直播间页面不显示聊天列表。
3. **抖音改版会失效**：DOM 抓取天生比官方 API 脆；选择器集中在 `relay.js` 的采集脚本里，改起来不难。
4. **中继只负责「入」**：发弹幕/礼物等互动不在能力范围。
5. **去重是进程内的**：中继重启后旧消息可能重播一次（脚本注入时会标记已有消息为已读，通常不会）。
