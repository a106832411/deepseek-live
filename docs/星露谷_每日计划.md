## 冬季（当前季节）

冬天户外**不长作物**，所以不种地、不浇水，重点做这些：

| 时段 | 做什么 | 原因 |
|---|---|---|
| 上午 | **挖矿** | 攒铜/铁/金、宝石、煤，为熔炉和工具升级 |
| 下午 | **钓鱼** | 冬天鱼价不错，稳定现金流 |
| 晚上 | 装船 + 睡觉 | 卖货 + 跨天 |

特殊情况：
- **下雪**：正常挖矿/钓鱼，雪不影响
- **运气好（DailyLuck 高）**：优先挖矿，稀有矿石概率高
- **运气差**：多钓鱼

## 春 / 夏 / 秋

| 时段 | 做什么 |
|---|---|
| 上午（不下雨） | 农场：浇水 / 收菜 / 翻地播种 |
| 下雨天 | 不用浇水 → **下矿** |
| 下午 | 运气好挖矿，否则钓鱼 |

## 当前 AI 实现（guard.py 的 plan_today）

```
season == winter:
    time < 12:00  → 挖矿
    time >= 12:00 → 钓鱼
否则:
    上午不下雨 → 农场
    上午下雨   → 挖矿
    下午       → 运气好挖矿，否则钓鱼
晚上（>=18:00）→ 装船 + 睡觉跨天
```
