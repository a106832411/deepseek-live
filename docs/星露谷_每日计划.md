## 🌱 春季（第 1 年重点：开荒 + 攒钱）

| 时间 | 做什么 |
|---|---|
| 每天上午（不下雨） | 浇水 → 收菜 → 有空地就翻地种**防风草/土豆/花椰菜** |
| 下雨天 | 不用浇水 → 下矿挖铜/铁 |
| 下午 | 运气好挖矿，运气差钓鱼/砍树 |
| 攒够钱 | 买草莓种子（复活节当天买最划算） |
| 打基础 | 砍树攒木材、砸石头攒石头，为鸡舍/熔炉做准备 |

**春季目标**：铜锭 5 个 + 2000 金（升级工具）、开始养鸡、攒 1 万金左右。

## ☀️ 夏季（赚钱爆发期）

| 时间 | 做什么 |
|---|---|
| 上午 | 浇水（夏天作物值钱：蓝莓/杨桃）→ 收菜 |
| 下雨天 | 下矿（夏天矿洞收益高） |
| 下午 | 钓鱼（夏天鱼价高）或继续挖矿 |
| 雷雨天 | 尽量别在户外，下矿/在家整理 |
| 夏 11 夏威夷宴会 | 去海边参加，带个好东西下锅加好感 |
| 夏 28 月光水母 | 晚上去海边看，纯活动 |

**夏季目标**：把农场作物铺满、攒钱买动物/升级工具。

## 🍂 秋季（收获 + 节日）

| 时间 | 做什么 |
|---|---|
| 上午 | 浇水 → 收菜（南瓜/蔓越莓最赚） |
| 下雨天 | 下矿 |
| 下午 | 运气好挖矿，否则钓鱼 |
| 秋 16 星露谷集市 | 去镇上参加，买星之果实（加体力上限） |
| 秋 27 幽灵节 | 晚上去镇上，迷宫拿金南瓜 |

**秋季目标**：囤钱、囤材料，准备过冬。

## ❄️ 冬季（不长作物，专心挖矿/钓鱼/加工）

| 时间 | 做什么 |
|---|---|
| 上午 | **挖矿**（铜/铁/金/煤/宝石） |
| 下午 | **钓鱼**（冬天鱼价稳定） |
| 雪天 | 照常，不影响 |
| 运气差 | 多钓鱼；运气好 | 多挖矿 |
| 冬 8 冰雪节 | 去森林参加冰钓比赛 |
| 冬 25 冬星节 | 去镇上参加，收礼物 |

**冬季目标**：攒矿石 → 熔炉烧锭 → 升级工具；攒钱等春天买种子。

## 🎉 节日清单（当天计划自动切换成「去节日」）

| 季节 | 日期 | 节日 | 地点 |
|---|---|---|---|
| 春 | 13 | 彩蛋节 | 镇上 |
| 春 | 24 | 花舞节 | 森林 |
| 夏 | 11 | 夏威夷宴会 | 海边 |
| 夏 | 28 | 月光水母 | 海边（晚上） |
| 秋 | 16 | 星露谷集市 | 镇上 |
| 秋 | 27 | 幽灵节 | 镇上（晚上） |
| 冬 | 8 | 冰雪节 | 森林 |
| 冬 | 25 | 冬星节 | 镇上 |

节日当天做法：
1. 上午先走到节日地点（镇上/森林/海边）
2. 参加节日（目前 AI 只做到「到场 + 停留」，节日小游戏还没自动化）
3. 节日结束后继续挖矿/钓鱼
4. 晚上照常装船睡觉

---

## 当前 AI 实现（`guard.py`）

```
如果是节日       → 去节日地点参加（到场停留）
冬天             → 上午挖矿，下午钓鱼
其他季节 上午    → 不下雨：农场（浇水/收菜/种地）
                  下雨：挖矿
其他季节 下午    → 运气好挖矿，否则钓鱼
时间 >= 18:00    → 装船 + 睡觉跨天
```
