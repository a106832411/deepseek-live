# 运行环境（依赖服务一键启动 / 健康检查）

鲸live 本体只是个控制台，真正干活的是几个本地依赖服务。这个页面（控制台左侧「系统设置 → 运行环境」）就是
**检测它们有没有起来 + 一键启动**，不用再手动开 PowerShell 敲脚本。

## 一、页面在哪、能做什么

- 控制台：`系统设置 → 🧰 运行环境`
- 每个服务一行：在线/离线、端口、当前状态说明、建议
- 离线且能自动发现的 → 有「一键启动」按钮（启动后等几秒会自动刷新）
- 由鲸live 启动的服务会标「鲸live 启动」，可以点「停止」；**不是鲸live 启动的不给停**（避免误杀你自己开的）
- 「会话总览 → 开播自检」里也会带出 TTS / OBS 两项状态

## 二、检测哪些东西

| key | 服务 | 怎么判断在线 | 一键启动 |
|---|---|---|---|
| `tts` | GPT-SoVITS 语音（说话/清唱都靠它） | 连 `tts.api_url` 的端口（默认 127.0.0.1:9881），顺带看一眼 9882 引擎 | ✅ 自动发现 / 可配置 |
| `obs` | OBS Studio | 连 `obs.port`（默认 4455 WebSocket） | ✅ 自动发现 / 可配置 |
| `ollama` | 本地模型 Ollama（省钱模式） | 连 127.0.0.1:11434（只有 AI 接口指向本机时才用这个） | ✅ 自动发现 / 可配置 |
| `python` | Python（清唱管线、星露谷脚本） | 跑一次 `python --version` | ❌（要你自己装） |
| `sing` | 真唱引擎 ACE-Step + Seed-VC（可选） | 检查 `sing.ace.*` 里的 python/脚本是否存在 | ❌（按 docs/清唱.md §6.5 部署） |

## 三、一键启动怎么找命令（优先级从高到低）

1. **`config.json` 里 `deps.*_start_cmd`**（控制台「全部配置 → 🧰 运行环境」可改，实时生效）
2. **自动发现本机路径**：
   - TTS：先读 `scripts/start-all.ps1` 里 `$Work = '...'` 指的工作目录（历史安装结构），拼 `gsv_gpu/run_gpu_api.ps1`；再找仓库同级/上级的 `whaletalk/gsv_gpu/run_gpu_api.ps1`
   - OBS：`D:\obs-studio\bin\64bit\obs64.exe`、`C:\Program Files\obs-studio\bin\64bit\obs64.exe`、`C:\Program Files (x86)\...`
   - Ollama：`%LOCALAPPDATA%\Programs\Ollama\ollama.exe`、`%LOCALAPPDATA%\AMD\AI_Bundle\Ollama\ollama.exe`、`%LOCALAPPDATA%\Ollama\ollama.exe`
3. 都找不到 → 按钮不显示，去配置里手填启动命令

启动命令就是一行普通命令行，例如：

```ini
deps.tts_start_cmd    = powershell -NoProfile -ExecutionPolicy Bypass -File "D:\...\whaletalk\gsv_gpu\run_gpu_api.ps1"
deps.obs_start_cmd    = "D:\obs-studio\bin\64bit\obs64.exe"
deps.ollama_start_cmd = "C:\Users\你\AppData\Local\Programs\Ollama\ollama.exe" serve
```

> 命令解析是**自己拆词**（引号里的路径带空格也没问题），不走 cmd.exe，所以不会出现 Windows 引号地狱。
> 启动后进程是独立后台进程，**关掉控制台不会把服务带走**。

## 四、API（外部脚本也能用）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/deps` | 探测所有依赖，返回 `{ok, services:[{key,name,ok,detail,startable,managed,port,command}], managed, port}` |
| GET | `/api/deps/check` | 同上（语义化别名） |
| POST | `/api/deps/start` | `{name:"tts"\|"obs"\|"ollama"\|"all"}`，启动后等 1.5~2.5 秒再探测，返回 `{ok,running,pid,command,source,log,services}` |
| POST | `/api/deps/stop` | `{name:"tts"}`，只停鲸live 启动的进程（`taskkill /T /F`） |

Electron 内走 IPC：`deps:get` / `deps:start` / `deps:stop`（`src/api.js` 会按环境自动选 IPC 或 HTTP）。

启动日志：`logs/deps-<name>.log`（stdout/stderr 都写进去，起不来先看它）。

## 五、端口被占用会自动顺延

以前 8788 被占用（比如上一份没关干净）时 Electron 会直接起不来。现在核心服务会
**8788 → 8789 → 8790 … 自动 +1 顺延**（最多 20 个），Electron 窗口等真正监听成功再开，
IPC 基址也用真实端口，不会白屏。

日志里会写明：`端口 8788 被占用，改用 8789`。

## 六、已知限制

1. **从某些 shell 启动 Electron 要先清 `ELECTRON_RUN_AS_NODE`**：如果环境里带着 `ELECTRON_RUN_AS_NODE=1`，
   Electron 会退化成纯 Node 运行（报 `Cannot read properties of undefined (reading 'whenReady')`）。
   命令行启动前先 `Remove-Item Env:\ELECTRON_RUN_AS_NODE`（`scripts/start-all.ps1` 已经处理）。
2. **TTS 首次启动很慢**：模型加载 1~3 分钟，点「一键启动」后端口要过一会儿才通；
   页面每 6 秒自动刷新一次，看到变为在线就行。中途别重复点。
3. **停止只对鲸live 启动的进程有效**：你自己开的 OBS/TTS 面板不给停（显示「离线」但没有停止按钮）。
4. **Python / 真唱引擎不提供一键装**：它们要装包/下模型，属于「先装好，再检测」。
5. **Ollama 检测**：AI 走 DeepSeek 云端时也会探测本机 11434（方便你随时切本地模型），离线是正常状态。
