> 目的：用本地模型“玩一天”星露谷，测实际 token 消耗；再结合 DeepSeek + 鲸live，估算真实直播一天的成本。

## 二、本地模型玩星露谷：实测数据

### 测试条件

- 模型：`qwen25-7b-local`（Qwen2.5-7B-Instruct Q3_K_M，Ollama，GPU）
- 模式：每轮让模型看一次游戏状态 → 输出最多 8 个动作（走位/锄地/斧头/镐）→ 脚本执行
- 游戏内时间：夏季第 3 天，从 06:10 跑到 21:40（约 11.5 游戏小时）

### 实测结果

```
轮次：7 轮
输入：17,322 tokens
输出：9,800 tokens
合计：27,122 tokens
单轮均值：输入 2,475 / 输出 1,400
```

### 推算一个完整游戏日（6:00 → 次日 2:00）

- 每轮约覆盖 100 游戏分钟 → 一天 1200 游戏分钟 ≈ **12 轮**
- 一天 tokens ≈ **12 × 3,875 ≈ 4.6 万**（保守算 5 万）
- **本地费用：0 元**
- 如果改用 DeepSeek（同样的调用量）：
  - 输入约 3.1 万、输出约 1.8 万
  - 错峰价 ≈ **$0.015 ≈ ¥0.11/天**
  - 高峰价 ≈ ¥0.22/天

### 效果评价（实话实说）

**链路完全通了，但“玩得不好”**：

- 模型能自己决定：走到某格 → 锄地/砍树/挖石头，动作都执行成功
- 但它在农场边缘乱锄（没有作物、没有规划），**钱还是 500，没赚到钱**
- 原因：7B 模型没有作物日历/价格表，且当前 prompt 只给了「周围格子」，没给「今天该种什么/该卖什么」的高层目标
- 下一步需要：作物利润表 + 每天先出「目标」再出动作，效果会明显不同

## 三、鲸live 直播回复（DeepSeek）实测

### 单条回复 token（真实采样）

用当前人设 + 典型弹幕实际调用 DeepSeek：

```
今天天气不错啊   → 是呀，阳光正好，适合出去玩呢。   in=224 out=10
进房欢迎         → 欢迎鲸鱼丸，来坐坐呀。           in=228 out=10
礼物感谢         → 谢谢阿糕的小心心，收到啦。       in=233 out=9
平均：输入 228 tokens / 输出 10 tokens
```

### 一天各档位的消耗与费用

DeepSeek 官方现价（deepseek-flash，单位 USD/百万 tokens）：
错峰：输入未命中 $0.15、命中 $0.003、输出 $0.6；高峰翻倍。

| 直播时长 | 假设回复量 | 一天 tokens（输入/输出） | 错峰费用（未命中/命中） | 高峰费用 |
|---|---|---|---|---|
| 2 小时 | 100 条 + 24 条口播 | 2.8 万 / 0.12 万 | ¥0.03 / ¥0.01 | ¥0.06 |
| **4 小时** | 300 条 + 48 条口播 | **7.9 万 / 0.35 万** | **¥0.10 / ¥0.03** | **¥0.20** |
| 6 小时 | 600 条 + 72 条口播 | 15.3 万 / 0.67 万 | ¥0.19 / ¥0.06 | ¥0.38 |

（汇率按 7.1 折算；缓存命中率按 85% 估算，因为系统人设固定会被缓存）

### 结论

**DeepSeek 一个月也就 3–30 元**，完全不是负担。之前的“一天 ¥50–150”是**每步都调大模型做游戏决策**的算法，不是现在这套。

## 五、省钱建议

1. **直播尽量放晚上**：北京时间 19:00–23:00 属于 DeepSeek 错峰（半价）
2. **人设别频繁改**：系统提示固定才能命中缓存，输入价从 $0.15 降到 $0.003（50 倍差价）
3. **游戏继续用本地 7B**：即使换 DeepSeek 一天也才 ¥0.1，但本地免费且不出网
4. **别把 `deepseek-chat` 换成 `deepseek-flash` 前先测**：实测 flash 默认开思考模式，`max_tokens` 小时会返回空内容（思考 token 用完了），需要显式关 thinking 或给更大 max_tokens
5. **模型名核对**：当前配置 `deepseek-chat` 可用；官方新价目表列的是 `deepseek-flash` / `deepseek-v4-pro`，后续可以按官方文档切换

## 六、下一步（游戏效果提升）

1. 加**作物利润表**（春/夏/秋各作物种子价、成熟天数、卖价）
2. 每天先出「今日目标」（如：种 20 个防风草、浇水、清理农场左上角）再出动作
3. 加**体力/时间预算**：低于 30 体力回屋，18:00 前收工
4. 加**取货/卖货**流程（把作物放进出货箱）
