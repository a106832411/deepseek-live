# 本地模型（省钱模式）

目标：把 AI 决策从「按 token 付费的云端接口」换成「本机 Ollama」，token 成本归零，只花电费。

## 1. 安装 / 确认 Ollama

本机已有（AMD AI Bundle 自带）：

```
C:\Users\49820\AppData\Local\AMD\AI_Bundle\Ollama\ollama.exe
```

版本 0.32.15。检查模型库连通性：

```powershell
curl.exe -sS -m 12 -o NUL -w "%{http_code}`n" https://registry.ollama.ai/v2/library/qwen2.5/manifests/7b
# 200 = 可直连下载
```

## 2. 下载模型

```powershell
# 建议单独指定模型目录，避免和旧格式混用
$env:OLLAMA_MODELS="D:\ollama-models2"
ollama pull qwen2.5:7b        # 约 4.7GB，Q4 量化，7900 GRE 16GB 可跑
# 备选：
# ollama pull qwen2.5:3b      # 约 2GB，更快更省显存
# ollama pull deepseek-r1:7b  # 带推理过程，慢一些
```

> 注意：不要用**旧版** Ollama 去读**新版**下载的模型目录（`manifests-v2` 格式），旧版 GC 会把不认识的 blob 删掉。

## 3. 启动服务并验证

```powershell
$env:OLLAMA_MODELS="D:\ollama-models2"
ollama serve                 # 监听 http://127.0.0.1:11434
ollama list                  # 应能看到 qwen2.5:7b
```

跑一句测速：

```powershell
curl.exe -sS http://127.0.0.1:11434/api/generate -d '{\"model\":\"qwen2.5:7b\",\"prompt\":\"用一句话介绍星露谷物语\",\"stream\":false}'
# 返回 JSON 里 eval_count / eval_duration 可算出 tokens/s
```

## 4. 切到鲸live

编辑 `.env`：

```ini
DEEPLIVE_AI_BASE=http://127.0.0.1:11434/v1
DEEPLIVE_AI_MODEL=qwen2.5:7b
DEEPLIVE_AI_KEY=ollama
```

重启鲸live，AI 回复就走本地模型，**不产生 token 费用**。

## 5. 成本对比

| 方案 | token 费用 | 说明 |
|---|---|---|
| DeepSeek 云端（每步调用） | ¥50–150/天 | 不推荐 |
| DeepSeek 云端（每天一次规划） | ¥0.2–1/天 | 规则脚本为主 |
| 本地 7B | ¥0 | 电费约 ¥0.1–0.3/天 |

## 6. 常见问题

- **显存不够/太慢**：换 `qwen2.5:3b`，或降低上下文（`num_ctx`）。
- **下载中断**：重新执行 `ollama pull qwen2.5:7b`，会续传。
- **想再接回云端**：把 `.env` 里 `DEEPLIVE_AI_BASE` 改回 `https://api.deepseek.com/v1` 即可。
