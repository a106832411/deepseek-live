## 六、星露谷 AI：修了一个大 bug + 加了主角控制

### 1. 存档崩溃（重要）

**现象**：游戏保存时卡死在「正在储存…」。
**原因**：StardewMCPBridge 的 `CompanionNPC` 没有无参构造函数，XmlSerializer 保存时报
`cannot be serialized because it does not have a parameterless constructor`。

**修复（已重新编译部署到 Mods）：**

1. 给 `CompanionNPC` 增加 `public CompanionNPC() : base() {}`
2. 加存档钩子：`GameLoop.Saving` 时把同伴临时移出地图，`GameLoop.Saved` 后再放回原位 —— 从根上避免自定义 NPC 被写进存档

> 自动化里没成功触发一次存档（键盘模拟不生效，走不到睡觉/退出），所以**明早你进游戏睡一觉或「保存并退出」验证一下**，如果不再卡「正在储存」就是好了。

### 2. 新增主角控制 actions

在 mod 里加了 5 个动作，AI 现在可以直接控制**主角**：

| action | 作用 |
|---|---|
| `player_move_to` | 主角寻路走到指定格子 |
| `player_warp` | 主角传送到指定地点 |
| `player_face` | 转向 |
| `player_use_tool` | 主角用锄头/水壶/斧头/镐 |
| `player_save` | 主动保存游戏 |
| `player_sleep` | 尝试让主角睡觉（反射调用 doSleep） |

实测 `player_move_to` 已生效（SMAPI 日志 `Player pathing to (12,10)`）。

## 七、新增的一键脚本

```powershell
# 启动全套（TTS + 鲸live + OBS）
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1

# 顺便启动星露谷 / 抖音中继
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1 -Game
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1 -Douyin

# 停止（默认连 OBS、游戏一起停）
powershell -ExecutionPolicy Bypass -File scripts\stop-all.ps1
```

脚本会等 TTS 模型加载完（首次 1-3 分钟）再继续，最后打印各端口状态。
